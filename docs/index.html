Aprender Mais

PIM IV – Plataforma educacional (aplicação desktop em C# / .NET)

Sobre o projeto

Plataforma educacional com três perfis, desenvolvida em camadas (Domínio, Aplicação, Infraestrutura e Desktop com Windows Forms), com testes em xUnit.

Aluno
Acessa conteúdos, realiza avaliações e consulta notas.
Secretaria
Avalia atividades e gerencia conteúdos.
Administrador
Cadastra secretarias e gerencia cadastros.

Arquitetura

CamadaResponsabilidade
DominioEntidades, regras de negócio e contratos de repositório
AplicacaoServiços (casos de uso), DTOs, sessão
InfraestruturaRepositórios em memória, BCrypt, relógio
DesktopWindows Forms (login e telas por perfil)
TestesxUnit

Como executar (Windows, .NET 10 SDK)

Rode criar-solucao.cmd e depois dotnet run --project AprenderMais.Desktop\AprenderMais.Desktop.csproj. Senha das contas de demonstração: 123456.

Ver código no GitHub
